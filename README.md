# Edan Cloud SA Learning Hub

Personal Cloud Solutions Architect learning dashboard.

## Live site
https://edanlinn.github.io

## Structure
- `index.html` – UI shell
- `styles.css` – responsive styling
- `data.js` – learning content and progress
- `app.js` – filtering / expansion / dashboard rendering

## Update workflow
After each Cloud SA answer is graded, update `data.js` with the new Day entry and commit to `main`.
